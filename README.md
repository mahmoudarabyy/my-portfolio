# محمود عربي — Next.js Portfolio

موقع عربي باتجاه RTL مبني بـNext.js App Router وReact، مع الحفاظ على التصميم والخطوط والصور الأصلية.

## التشغيل

تحتاج Node.js 22.12 أو أحدث وpnpm 11.25.0.

```sh
corepack enable
corepack prepare pnpm@11.25.0 --activate
pnpm install
pnpm dev
```

إذا لم يتوفر Corepack: `npm install --global pnpm@11.25.0`.
افتح http://localhost:3000. لا تستخدم Live Server أو ملف HTML مباشرة.

```sh
pnpm test
pnpm build
pnpm start
```

## الصفحات

- `/`: الرئيسية والمشاريع المميزة.
- `/projects`: جميع المشاريع مع الفلترة.
- `/projects/[slug]`: دراسة حالة مستقلة لكل مشروع، مع metadata وصورة مشاركة.
- `/studio`: لوحة Sanity، أو تعليمات الربط إذا لم تُضبط المتغيرات.
- `/sitemap.xml` و`/robots.txt`.

الروابط القديمة `index.html` و`projects.html` و`project-details.html?id=...` و`project-details.html?project=...` تتحول تلقائيًا إلى المسارات الجديدة. المشروع غير الموجود يعرض 404.

## إدارة المحتوى

اتبع [دليل إعداد Sanity](./SANITY_SETUP.md).

- بدون متغيرات Sanity: المشاريع العشرة الحالية من `data/projects.json`.
- بعد الربط: المصدر الوحيد هو المشاريع المنشورة في Sanity. المسودات لا تظهر للزوار.
- حذف أو إلغاء نشر كل المشاريع يعرض قائمة فارغة فعلًا، ولا يعيد البيانات التجريبية.
- تغييرات المحتوى يعاد التحقق منها كل 60 ثانية. أول زيارة بعد انتهاء المدة قد تحصل على النسخة السابقة بينما يتم التحديث في الخلفية.
- لا يوجد رمز كتابة سري في كود المتصفح؛ إدارة المحتوى تتم بتسجيل الدخول داخل Studio.

## البنية

- `app/(site)/`: صفحات البورتفوليو والتصميم.
- `app/(studio)/`: لوحة الإدارة بتخطيط منفصل عن CSS الموقع.
- `components/`: الأقسام المشتركة والتفاعلات.
- `lib/projects.js`: قراءة المحتوى المنشور من Sanity أو المصدر المحلي.
- `lib/project-data.mjs`: قواعد الفرز والفلترة وتوحيد البيانات.
- `public/`: الصور والخطوط؛ تحسين صور المشاريع من خلال `next/image`.
- `sanity/`: نموذج بيانات المشاريع وإعداد لوحة الإدارة.
- `scripts/import-sanity.mjs`: استيراد المشاريع والصور الحالية مرة واحدة.
- `tests/`: تحقق من بيانات المشاريع، الصور، الفلترة والروابط.

## النشر على Vercel

الإعدادات موجودة في `vercel.json`: Framework = Next.js، والتثبيت من lockfile. استخدم Node.js 24.x أو نسخة متوافقة ≥22.12. في إعدادات Vercel ألغِ أي Output Directory قديم مثل `.` أو `public`، واستخدم الإعداد الافتراضي لـNext.js. ضع `NEXT_PUBLIC_SITE_URL` على رابط الموقع الفعلي.

بعد اعتماد النسخة المحلية، اعمل commit وpush للمستودع المتصل بـVercel. لم ينفذ التحويل المحلي نشرًا أو push تلقائيًا.

## ملاحظات

- فورم الاستشارة يجهز رسالة في برنامج البريد لدى الزائر، ولا يدّعي إرسالها من السيرفر. لا توجد خدمة إرسال بريد أو قاعدة بيانات للطلبات ضمن هذا التحويل.
- محتوى المقالات وروابط السوشيال العامة الموروثة ما زالت تحتاج روابطك النهائية؛ نقل المشاريع إلى CMS لا يدير المقالات تلقائيًا.
- بيانات الصور الحالية في `data/image-dimensions.json` لحفظ أبعادها. الصور المرفوعة إلى Sanity تحمل أبعادها في رابط الأصل.
- `server.ps1` لم يعد مستخدمًا؛ خادم Next.js هو طريقة التشغيل المحلية.

## المظهر

من القائمة الرئيسية استخدم مفتاح داكن / فاتح. يُحفظ الاختيار محليًا في المتصفح، ويطبق قبل ظهور الصفحة. الوضع الداكن هو الافتراضي، وصور المشاريع لا تتغير ألوانها. المظهر يخص الموقع فقط؛ لوحة Sanity لها إعدادات مستقلة.

## الحركة وتنسيق المشاريع

الكروت تحتفظ بتوزيع النسخة الأولى وصورها بأبعادها الأصلية وبادج السنة الأخضر المائل. الخطوط وأحجامها من التصميم الأصلي. تظهر الأقسام تدريجيًا عند دخول الشاشة، مع تكبير بسيط للصورة عند التفاعل. الحركة تحترم إعداد تقليل الحركة، ويبقى المحتوى ظاهرًا بدون JavaScript. يمكن تغيير أيقونة المشروع من Sanity بعد الربط.
